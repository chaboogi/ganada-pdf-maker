# 가나다 계단 · PDF용 맞춤 자료 만들기

가나다 계단의 PDF AI 재구성 파트입니다. 교사가 수업 자료 PDF를 올리면 학생 그룹의 한국어 읽기 수준에 맞게 원본 지면 배치 그대로 재구성합니다. 교사는 원본과 나란히 검토하고 승인한 뒤 학생 화면으로 보내거나 그룹별 PDF로 저장할 수 있습니다.

## 사용 방법
1. `index.html`을 GitHub Pages 등에서 엽니다.
2. 첫 화면에서 PDF를 올리고 변환할 쪽(기본 4쪽, 최대 10쪽), 받을 학생 그룹, 교과를 고릅니다.
3. **4. AI 연결** 칸에 Anthropic API 키(`sk-ant-`로 시작)를 넣고 저장합니다.
4. ‘자료 재구성 시작’을 누릅니다. 쪽마다 30초~1분 걸립니다.

‘예시 자료로 보기’는 API 키 없이 볼 수 있습니다.

## API 키
- 키는 쓰는 사람의 브라우저(localStorage)에만 저장되고, Anthropic API로만 직접 보내집니다. 이 저장소나 페이지 코드에는 키가 들어 있지 않습니다.
- 사용한 만큼 키 계정에 요금이 나옵니다. 교과 파악에는 Claude Haiku 5.5, 쪽별 재구성과 번역에는 Claude Sonnet 5.5를 씁니다.
- 공용 컴퓨터에서는 다 쓴 뒤 ‘키 지우기’를 눌러 주세요.
- claude.ai 아티팩트 안에서 열면 키 없이 Claude를 씁니다.

## 구성
- `index.html`: 화면 전체(한 파일). pdf.js, html2canvas, jsPDF는 cdnjs에서 불러옵니다.
- `fonts/`: Pretendard 글꼴과 라이선스(SIL OFL 1.1)
- `examples/`: 예시 자료(민사 재판) 원본 지면 이미지

## 제한
- 글자를 선택할 수 있는 PDF만 재구성합니다. 스캔본이나 그림으로만 된 쪽은 원본 그대로 둡니다.
- 모국어 대역은 AI 초안이라 ‘검증 전’으로 표시됩니다.
