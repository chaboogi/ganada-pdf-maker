# 가나다 계단 · PDF용 맞춤 자료 만들기

가나다 계단의 PDF AI 재구성 파트입니다. 교사가 수업 자료 PDF를 올리면 학생 그룹의 한국어 읽기 수준에 맞게 원본 지면 배치 그대로 재구성합니다. 교사는 원본과 나란히 검토하고 승인한 뒤 학생 화면으로 보내거나 그룹별 PDF로 저장할 수 있습니다.

## 사용 방법
1. claude.ai 아티팩트로 `index.html`을 엽니다. (AI 재구성은 claude.ai 안에서 열었을 때만 작동합니다.)
2. 첫 화면에서 PDF를 올리고 변환할 쪽(기본 4쪽, 최대 10쪽)과 받을 학생 그룹을 고릅니다.
3. ‘자료 재구성 시작’을 누릅니다. 처음 한 번 AI 사용 허락을 묻고, 쪽마다 30초~1분 걸립니다.
4. 결과 화면에서 바뀐 표현을 확인·수정하고 그룹별로 승인합니다. ‘← 이전 화면’으로 설정을 바꿨다가 ‘바꾼 결과로 돌아가기’로 다시 돌아올 수 있습니다.

‘예시 자료로 보기’는 AI 없이 볼 수 있습니다. GitHub Pages 등 claude.ai 밖에서 열면 예시 자료만 볼 수 있습니다.

## 화면에서 보이는 것
- 어려운 표현: 학생 수준에 맞는 쉬운 말로 바꾸고 밑줄로 표시합니다. 누르면 원래 표현이 나옵니다.
- 설명이 필요한 표현·핵심어: 옆에 `+` 표시가 붙고, 누르면 뜻풀이가 나옵니다.
- 핵심어: 나오는 곳마다 위에 학생 모국어(우즈베크어·몽골어·중국어) 뜻을 작게 함께 적습니다.
- 문단: 문단 번호 표시(동그라미 번호 등)와 첫 줄 들여쓰기를 기준으로 문단을 나눠, 원본 문단 자리에 맞춰 다시 씁니다.

## 구성
- `index.html`: 화면 전체(한 파일). pdf.js, html2canvas, jsPDF는 cdnjs에서 불러옵니다.
- `fonts/`: Pretendard 글꼴과 라이선스(SIL OFL 1.1)
- `examples/`: 예시 자료(민사 재판) 원본 지면 이미지

## 제한
- 글자를 선택할 수 있는 PDF만 재구성합니다. 스캔본이나 그림으로만 된 쪽은 원본 그대로 둡니다.
- 핵심어 모국어 뜻은 AI가 만든 것이라 교사가 확인해 주세요.
